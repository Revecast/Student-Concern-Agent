# ADR-035 — Schedule the demo reset for the 12/2–12/3 slots with daily-recurring alerts

**Date:** 2026-11-24 · **Status:** Accepted
**Deciders:** Sean Speer · **Supersedes:** none

## Context

The reset must run the evening before the demo so that Jordan's alert lands at 2:00 AM on the demo day. Sean asked for items that come up every day for a few weeks so there is always something to show.

## Options considered

| Option | For | Against |
|---|---|---|
| **A — Book the 12/2–12/3 slots** | Matches Sean's scheduled demo. | Requires a reset the evening before each demo. |
| **B — Tomorrow (2026-11-25)** | Earliest option. | Not Sean's scheduled demo. |
| **C — Not scheduled yet** | Keeps options open. | Leaves the reset undated. |

## Decision

The demo reset is dated to the 12/2–12/3 demo slots, and daily alerts are planned to keep new items coming up through mid-December. The daily-alert plan is for Sean to review before anything is built.

## Why

Sean's demo is on those dates, and he wants a steady flow of items to show.

## Consequences

**Accepted costs:**
- Orchestrate will show the daily-alert plan for review before building it.

**What this forecloses:**
- Running the reset on 2026-11-25 for this demo.

**Revisit if:**
Sean's demo date changes.
